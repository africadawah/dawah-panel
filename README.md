# لوحة الباحث الدعوي

لوحة تحكم مهارة «الباحث الدعوي» لجمعية الدعوة والتعليم باللغات الأفريقية.

- `index.html` — اللوحة (لا تحتاج تعديلًا أسبوعيًا).
- `data.json` — بيانات الأسئلة والردود والكتب واللغات، تُحدَّث كل أسبوع.
- `logo.png` — شعار البيت الأفريقي.

## التشغيل على GitHub Pages
Settings ← Pages ← Source: Deploy from a branch ← Branch: `main` / `(root)` ← Save.

## التحديث الأسبوعي
أضف عناصر الأسبوع الجديد إلى `items` وأضف الأسبوع إلى `weeks` في `data.json`، وغيّر `updated`.
قرارات المراجعة (اعتماد/نشر/تعديل) تُحفظ في متصفح المراجع، ويصدّرها من «الإعدادات».
